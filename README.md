# 2D_Semiconductor_150k_Master_Dataset
This dataset contains over 150,000 unique entries of 2D semiconductor materials, including bandgap values, crystal structures, and key electronic properties. The data has been collected and organized for machine learning research, high‑throughput screening, and computational materials science applications.

Contents:

Bandgap values (eV)

Crystal structure information

Energy properties (formation energy, stability indicators)

Metadata for reproducibility

Applications:

Machine learning model training for bandgap prediction

Screening of 2D semiconductors for optoelectronic devices

Benchmark dataset for computational materials science research

Format:

CSV and JSON files

150,000+ rows with labeled features
